# Open WebUI memory text: generic Gemma 4 builds

Source text for Open WebUI memories (Settings → Personalization → Memory → Manage → Add memory). Add all three on the M5 Max Studio (where project chats happen) and on each generic host once its Open WebUI is up. The M5's own memories stay as they are; memory 1 keeps local models from mixing the two projects. Values here are generic: no addresses or personal details.

1. Generic Gemma 4 build project: scripted single-model local LLM builds for M-series Mac Studios that host Open WebUI for friends and family on the LAN. Lives in the ZuulRulez repo, MacLLM branch, gemma/ folder (README, bin/, rebuild/, docs/). Each host runs under one macOS admin account named houdini (only account, volume owner, runs the stack, Open WebUI admin). First host: Mac Studio M1 Max 32 GB, rebuilt on macOS Golden Gate 27 in Oct 2026. M5 Max items (Flash-Next, mlx-serve, Auto Router, Caddy, RAID, service toggles, RemoveMacAI, GPU wired-limit tuning, the top-level install.sh) are not part of these builds.
2. Generic Gemma build stack: all command line, no GUI app. Model server = LaunchDaemon com.gemma.llm (runs ~/ZuulRulez/gemma/bin/gemma-serve.sh as houdini at boot) on 127.0.0.1:1234, OpenAI API /v1. ENGINE in ~/.config/gemma.env: llamacpp (default; Homebrew llama-server, GGUF Q4_0 + vision projector, model id gemma-4-26b-a4b-it-qat) or mlx (mlx-vlm in ~/mlx-venv, model id mlx-community/gemma-4-26B-A4B-it-qat-4bit). Context 16384 on 32 GB, 32768 on 48 GB+, NP=2 requests at once. Open WebUI = LaunchDaemon com.openwebui.serve on 0.0.0.0:8080, venv ~/open-webui-venv, data ~/open-webui-data. Commands: ~/bin/gemma-up.sh (RESTART=1 after env changes), ~/bin/gemma-down.sh, ~/ZuulRulez/gemma/rebuild/40-verify.sh, ~/bin/owui-upgrade.sh; logs ~/Library/Logs/gemma-llm.log and open-webui.log. Switch engine: ENGINE=mlx ~/ZuulRulez/gemma/bin/install-gemma-stack.sh. New users sign up as pending and houdini approves them.
3. Generic Gemma rebuild procedure (gemma/docs/rebuild-runbook.md): from the MBP over SSH run 00-preflight.sh and 10-upgrade-os.sh (Golden Gate via softwareupdate as the volume owner); Erase All Content and Settings over Screen Sharing; one visit to the machine for Setup Assistant (create houdini, FileVault on, Remote Management and Remote Login on); then everything over SSH: 30-bootstrap.sh, gemma/bin/install-gemma-stack.sh, 40-verify.sh, llm-bench.py per engine. After a power failure the Mac restarts itself; unlock FileVault by SSH as houdini (Ethernet) and both daemons start with no desktop login.

On a generic host, also add the repo-workflow memory from the M5 if local chats there will produce repo changes (commit as Pdl_Pwr, one commit and one CHANGELOG line per change, never commit models, Open WebUI data, secrets, LAN addresses or /Users paths).
